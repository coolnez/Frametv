# Прошивка Samsung The Frame 2020 (QE65LS03TAU, Tizen 5.5)

## Коротко

| Что | Возможно? | Риск |
|---|---|---|
| Официальное обновление прошивки (по сети или с USB) | ✅ да | низкий |
| Переустановка той же/последней официальной версии с USB | ✅ да | низкий |
| «Кастомная» прошивка, root, замена оболочки | ❌ для 2020 Tizen публичных рабочих решений нет | очень высокий: «кирпич», потеря гарантии, Art Mode и DRM (Netflix, Кинопоиск) |
| Свои приложения через Developer Mode (Tizen Studio, `.wgt`) | ✅ да, без перепрошивки | низкий |
| Управление ТВ по локальной сети (этот проект) | ✅ да, без перепрошивки | нет |

Прошивки Tizen подписаны Samsung, загрузчик проверяет подпись (secure boot). Любая
модифицированная прошивка будет отвергнута или, при обходе через сервисное меню/UART,
приведёт к неработающему ТВ. Поэтому «простое управление приложениями и режимом The Frame»
делаем **не перепрошивкой**, а через штатный локальный API телевизора — см. [README](../README.md).

## Как определить свою ветку прошивки

`Настройки → Поддержка → Об этом ТВ`:

- **Код модели**: `QE65LS03TAUXRU`
- **Версия ПО**: `T-NKMDEUC-XXXX.X` → ветка прошивки **`T-NKMDEUC`**, число после дефиса — номер версии.

Скачивать можно **только** файл для этой ветки (`T-NKMDEUC`). Прошивка от другой модели/ветки не установится или повредит ТВ.

## Способ 1. По сети (рекомендуется)

1. `Настройки → Поддержка → Обновление ПО → Обновить сейчас`.
2. Не выключайте ТВ и не отключайте питание до перезагрузки.
3. По желанию: `Автообновление` — вкл/выкл.

## Способ 2. С USB-флешки (если по сети не обновляется или нужно переустановить)

1. На ПК откройте samsung.com → ваш регион → Поддержка → введите модель **QE65LS03TAU** → «Загрузки/Прошивка».
2. Скачайте файл прошивки **USB type** для ветки `T-NKMDEUC` и сравните версию с текущей.
3. Флешка: отформатировать в **FAT32** (или exFAT), без других файлов.
4. Распаковать архив/запустить self-extract `.exe` **в корень** флешки. В корне должна оказаться папка `T-NKMDEUC` (не вложенная в другую папку).
5. Вставить флешку в ТВ (One Connect / порт USB) → `Настройки → Поддержка → Обновление ПО → Обновить сейчас` → ТВ предложит обновиться с USB.
6. Дождаться перезагрузки (5–15 мин). **Не выключать питание.**

Если ТВ пишет «Не найдено обновлений» — либо версия на флешке не новее установленной, либо папка лежит не в корне.

## Способ 3. Свои приложения без перепрошивки — Developer Mode

Это то, что обычно хотят получить от «перепрошивки»: запустить своё приложение на ТВ.

1. На ТВ откройте `Apps` (Приложения) и на пульте наберите `1 2 3 4 5`.
2. `Developer mode` → **On**, укажите IP компьютера → перезагрузите ТВ (долгое нажатие питания).
3. На ПК: Tizen Studio + TV Extensions, `Certificate Manager` → профиль **Samsung** (нужен аккаунт Samsung).
4. Подключение: `Device Manager → Remote Device Manager → +` (IP ТВ, порт 26101), затем сборка и установка `.wgt`.

Developer Mode не затрагивает прошивку и выключается в том же меню.

## Чего НЕ делать

- Не меняйте параметры в сервисном меню (`Info → Menu → Mute → Power` в режиме ожидания): смена `Model`/`Panel`/`Option` может отключить Art Mode, датчики и One Connect.
- Не ставьте прошивки с форумов и прошивки других регионов/моделей.
- Не отключайте питание во время обновления.

## После обновления

Локальный API может меняться между версиями ПО. После обновления проверьте `frametv status`
и `frametv art`. Если сопряжение «слетело» — удалите `~/.frametv/token.txt` и запустите `frametv setup <IP>` снова.
