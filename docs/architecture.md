Порты и адаптеры (hexagonal). Бизнес-правила не знают ни про HTTP, ни про Samsung API.

## Решения

| Решение | Почему |
|---|---|
| Управление по сети вместо перепрошивки | Прошивка подписана; штатный API даёт всё нужное без риска ([firmware.md](firmware.md)). |
| `samsungtvws` как транспорт | Поддерживаемая библиотека, умеет Art API (в т.ч. загрузку фото по D2D-сокету). Изолирована в одном адаптере — при смене API меняется один файл. |
| Один `RLock` на адаптер | ТВ плохо переносит параллельные WebSocket-сессии одного клиента. |
| Whitelist кнопок | API не становится прокси для `KEY_FACTORY` и подобных. |
| Удаление только `MY_…` | Нельзя случайно удалить купленные картины Art Store. |
| Необязательный `FRAMETV_API_TOKEN` | В домашней сети по умолчанию без пароля; при проброс наружу/гостевой Wi-Fi — включается одной переменной. |
| Конфиг: env > `~/.frametv/config.json` | Удобно и для ручного запуска, и для systemd/Docker. Токен ТВ лежит рядом и в git не попадает. |
| Загрузка фото сырым телом запроса | Без лишней зависимости `python-multipart`. |
| Новый каталог = один класс с `search/get/download` | Порт `ArtCatalog`; добавить музей — добавить класс в `MUSEUM_CATALOGS`. |
| Без API-ключей, только public domain/CC0 | Работает «из коробки», законно для домашнего показа. Rijksmuseum/Europeana требуют ключ — можно добавить отдельным адаптером. |
| HTTP-клиент с allowlist хостов и лимитом размера | Сервер не скачивает произвольные URL (нет SSRF через API), оригиналы >40 МБ отбрасываются в пользу меньшей версии. |
| Кэш `каталог:id → content_id` в config.json | Повторный показ не перезаливает картину и не забивает память ТВ. |
| Каталог Samsung = содержимое ТВ (`SAM-…`, `MY-C0008`) | Облачный каталог Art Store закрыт; локальный API видит только загруженное на ТВ. |

## Ограничения

- «Выключить» = удержание POWER 3 с. Короткое нажатие на The Frame лишь переключает ТВ ↔ Art Mode.
- Включение из глубокого сна — только Wake-on-LAN; на ТВ должна быть включена опция «Включение с мобильного».
- Слайд-шоу: на 2020 модели команда `set_auto_rotation_status`, на 2022+ — `set_slideshow_status`; адаптер пробует обе.
